# Skill: Карта возражений + оценка обработки по LAER

## Когда применять

- Вход: транскрипт с тайм-кодами.
- Выход: массив `objections[]` в формате контракта CallLens (см. `prompt.md`
  и `.qoder/rules/sales-objections-laer.md`) + coaching-приоритеты.

## Процедура

1. Найти все явные возражения клиента и скрытые сигналы сомнения (вопросы-
   колебания, паузы/уклонения после цены, «надо подумать»). Скрытые —
   с `confidence` ≤ 0.5.
2. Классифицировать по категориям: цена, сроки, потребность/соответствие,
   доверие/риск, полномочия/процесс, конкурент, реализация.
3. Для каждого возражения: точная цитата клиента, тайм-код, стадия звонка,
   severity (low/medium/high по влиянию на сделку).
4. Оценить обработку менеджером по пяти шагам LAER:
   - Listen — клиентская реплика завершена до ответа менеджера;
   - Acknowledge — признание значимости concern'а;
   - Explore — вопрос о причине возражения;
   - Respond — релевантные доказательства/варианты именно на это возражение;
   - Confirm — проверка снятия вопроса.
   Общий питч не засчитывается как Respond.
5. Статус обработки: resolved / partially_resolved / deferred / unresolved /
   not_observable.
6. Из неразрешённых возражений сформировать максимум 3 coaching-приоритета:
   observed_moment, impact, replacement_phrase, cue, success_signal;
   + follow-up условие проверки на следующем сопоставимом звонке.

## Запреты

- Выдуманные цитаты; засчёт шагов LAER без наблюдаемой реплики менеджера.
- Изменение имён полей контракта `objections[]`.
