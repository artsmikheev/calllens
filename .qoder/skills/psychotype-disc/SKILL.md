# Skill: DISC-психотипирование клиента по транскрипту

## Когда применять

- Вход: транскрипт звонка с тайм-кодами (формат CallLens
  `[MM:SS–MM:SS] Speaker N: …`) и, опционально, метаданные.
- Выход: `disc_profile` (оценки D/I/S/C 0–100, primary, confidence) +
  evidence-цитаты + контрдоводы + playbook для менеджера.

## Процедура

1. Отделить реплики клиента от реплик менеджера. Если роли ненадёжны
   (`role_warning`), анализировать только явно клиентские реплики и снизить
   confidence минимум на 0.2.
2. Для каждого фактора D/I/S/C собрать речевые маркеры (см. таблицу в
   `.qoder/rules/psychotype-disc.md`): темп и длина реплик, лексика
   (цифры/эмоции/статус/гарантии), структура аргументации, реакция на
   давление и риски.
3. Каждый засчитанный маркер подтвердить точной цитатой с тайм-кодом.
   Цитата обязана дословно присутствовать в транскрипте.
4. Оценить выраженность каждого фактора 0–100 и общий confidence:
   - ≥0.8 — несколько независимых цитат по доминирующему фактору, мало
     противоречий;
   - 0.55–0.8 — цитаты есть, но есть контрдоводы или мало данных;
   - <0.55 — гипотеза, явно помечать «требует проверки в следующем звонке».
5. Сопоставить доминирующий фактор со стилем CallLens: D→«Результатный
   стратег», I→«Визионер-вдохновитель», S→«Надёжный партнёр», C→
   «Доказательный эксперт».
6. Сформировать рекомендации: как начать разговор, какие аргументы
   использовать, чего избегать — по доминирующему фактору.

## Запреты

- Клинические, кадровые, демографические выводы; утверждения о неизменном
  характере.
- Выдуманные или пересказанные «цитаты».
- Копирование текстов коммерческих опросников (TTI, Crystal, Everything Disc).
