# Big Five (OCEAN) по транскрипту звонка

Big Five — академическая модель черт (Costa & McCrae; открытая литература).
В CallLens используется **не как психодиагностика**, а как наблюдаемая
коммуникационная гипотеза: шкалы 0–100 (условные перцентили выраженности
в данном разговоре) с обязательными цитатами-доказательствами.

## Речевые маркеры факторов

| Фактор | Высокий балл (маркеры в репликах) | Низкий балл |
|---|---|---|
| **Openness** (O) | новые идеи, «а что если», интерес к экспериментам, нестандартные сравнения | опора только на проверенное, отклонение новых подходов |
| **Conscientiousness** (C) | структура, сроки, критерии, детали, обязательность, методичные вопросы | хаотичная смена тем, игнорирование договорённостей |
| **Extraversion** (E) | длинные инициативные реплики, высокая энергия, перебивание, широкий круг тем | короткие ответы, ожидание вопросов, сдержанность |
| **Agreeableness** (A) | согласие, поиск компромисса, тёплая лексика, доверие | спор, жёсткий торг, скепсис, конкуренция |
| **Neuroticism** (N) | выраженные опасения, катастрофизация рисков, давление эмоций, «а если не получится» | ровное спокойствие при обсуждении рисков |

## Обязательные требования

1. Каждая шкала сопровождается минимум одной цитатой с тайм-кодом в
   `personality_profile.evidence.big_five` (signal = имя фактора). Без
   наблюдаемого сигнала шкала возвращается как `null`/50 с пометкой
   low-confidence, а не выдумывается.
2. Выводы по одному звонку — гипотеза; не переносить на личность клиента,
   не использовать для кадровых или клинических заключений.
3. При `role_warning=true` профиль provisional; не атрибутировать реплики
   менеджеру как клиентские.
4. Не смешивать Big Five с DISC: это разные срезы; `disc_profile` и
   `big_five_scores` заполняются независимо, но из одних и тех же цитат.

## Формат данных (контракт)

```json
{"openness": 0, "conscientiousness": 0, "extraversion": 0, "agreeableness": 0, "neuroticism": 0}
```
