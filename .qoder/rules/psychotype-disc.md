# DISC-профилирование клиента (наблюдаемый паттерн)

DISC — модель наблюдаемого поведения/коммуникации (не клинический инструмент).
В CallLens четыре буквенных фактора связаны с четырьмя русскими стилями:

| Фактор | Стиль CallLens | Речевые маркеры (только реплики клиента) |
|---|---|---|
| **D** (Dominance) | Результатный стратег | короткие директивные реплики; вопросы «сколько», «когда», «какой результат»; требования сроков, контроля, решений; нетерпимость к долгим вступлениям |
| **I** (Influence) | Визионер-вдохновитель | эмоциональная лексика, истории, образы будущего; статусные маркеры; быстрая смена тем; реакции на энтузиазм, а не на цифры |
| **S** (Steadiness) | Надёжный партнёр | вопросы о поддержке, команде, гарантиях, рисках изменений; спокойный ровный темп; поиск согласия и подтверждения безопасности |
| **C** (Compliance) | Доказательный эксперт | запросы цифр, документов, методик, сравнений; уточняющие детали вопросы; аккуратные формулировки; скепсис без доказательств |

## Обязательные требования

1. Каждый фактор получает оценку 0–100 (наблюдаемая выраженность) и общий
   `confidence` (0–1). Вывод без точной цитаты из транскрипта с тайм-кодом
   запрещён — цитаты не выдумывать и не paraphrase'ить.
2. Минимум 2 цитаты-доказательства на доминирующий фактор; при наличии —
   контрдоводы (реплики, противоречащие профилю).
3. При `confidence < 0.55` профиль формулируется как рабочая гипотеза.
4. Анализ проводится только по репликам клиента; при `role_warning=true`
   DISC-профиль помечается как provisional.
5. Запрещены выводы о личности, характере «вообще», клинике, демографии.
   Оценивается коммуникационный паттерн в этом звонке.

## Формат данных (контракт `personality_profile.disc_profile`)

```json
{"d": 0, "i": 0, "s": 0, "c": 0, "primary": "D|I|S|C|none", "confidence": 0.0}
```

Источник методологии: общедоступные описания модели DISC (Wikipedia: DISC
assessment, CC BY-SA; Marston, "Emotions of Normal People", 1928 —
общественное достояние как идея). Коммерческие опросники (TTI, Everything
Disc, Crystal) не копировать — их тексты лицензионно закрыты.
